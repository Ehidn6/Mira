# Mira

Нативная экспериментальная MiraOS, графовый язык и его bootstrap-компилятор. Основной проект — `projects/MiraOS`. Отдельная Linux IDE удалена; среда разработки развивается внутри MiraOS.

- `./launch-miraos.sh` — загрузить MiraOS в QEMU с USB-клавиатурой. Готовый образ используется повторно; изменения исходников вызывают пересборку.
- `./run-miraos.sh --build` — принудительно пересобрать образ без запуска.
- `./install-miraos-desktop.sh` — установить пункты запуска, справки и экспорта в меню приложений.
- `./launch-miraos.sh --context` — открыть актуальный `MIRA_CONTEXT.md`.
- `./launch-miraos.sh --export` — извлечь исходник, сохранённый внутри MiraOS.
- `cargo build -p mira-lang` — собрать компилятор и точечные инструменты работы с исходниками.

Начало работы для помощника: `AGENTS.md`. Синтаксис и проверяемые примеры: `language/README.md`. Фактическое состояние, управление, ограничения и долгосрочный замысел: `MIRA_CONTEXT.md`. Не читать весь проект заранее.

Граф задаёт экземпляры, связи и вложенные Z-пространства; внутри ячеек остаётся текстовый код. Файлы хранения не равны экземплярам ячеек. Linux пока нужен для bootstrap-сборки и QEMU; сам нативный образ не использует Linux runtime. Загрузка на физическом компьютере, сеть/ChatGPT и полная самокомпиляция ещё не готовы.
